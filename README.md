# dsh-bili-develop

让 DeepSeek Harness 桌面版里的“大肥鱼”在指定工作区的**唯一对话**中浏览B站、形成评价、学习表达，并在使用者设置的边界内互动。

公开版本 **0.1.0** · 内部包名 `dsh-bilibili-harness` · GPL-3.0-or-later。

## 功能

- 手动读取视频；关键词、实际TAG检索，或按基础人设与学习兴趣自主选择推荐视频。
- 字幕评价、ASMR评论区样本总结、可选本机讲话转写。没有画面或实际收听依据时不会声称看过完整视频。
- 每日轮次/分析/模型调用额度、24小时制活动时段、暂停恢复；封面记录、分页筛选与清理。
- 评论预览、逐条确认或自动评论；关键词互动、楼中楼独立额度及已关注账号的受控@提及。
- 使用者身份与普通粉丝分区，友善度评分；普通联系人达到60分且处于前100名才有私信回复资格。
- 基础人设由使用者编辑；迭代人设由模型在日终比较新旧经历后自主增减。表达来源、历次复盘和反思创意保存在原工作区。
- 把他人对自己评论或私信表达的反馈作为反思候选；私信只派生固定脱敏建议。使用者给方向建议，模型自主决定是否采用。
- 可选80分自动关注、100分每日主动私信，独立开关默认关闭。已关注不占关注次数，主动私信仍受额度、排名、冷却与隐私审核约束。
- 周总结图文草稿、本地配图；发布始终需要使用者审核。结果未知保留尝试记录，不自动重发。

## 隐私边界

**唯一对话会保留上下文，不能同时保证私信与公开输出的严格隔离。** 本版对识别到的凭据、联系方式、使用者身份、本地路径及私信片段做输入脱敏和外发校验；原对话处理过私信后，公共自动发送停止，手动发送需要逐条隐私审核。跨联系人自动私信也受同样保护，100分不会绕过。

模型可能改写或推断敏感信息，正则和片段检测无法保证零泄露。消息库及原对话没有由插件加密；Windows账号凭据使用当前用户DPAPI保护。开启私信前请读[SECURITY.md](SECURITY.md)，了解数据流、保留与审核限制。

## 安装

目标：**DSH桌面版0.2.1-rc.2**（包声明范围 `<0.3.0`），使用Node.js24及兼容Python环境。其他宿主版本需要另行验证。

1. 在[Releases](https://github.com/a-freshcat/dsh-bili-develop/releases)下载 `dsh-bili-develop-0.1.0-source.zip`，校验同页SHA256，解压到准备长期保留的目录。
2. 在解压目录运行 `node scripts/install-desktop.mjs`，只预览安装目标。
3. 确认目标正确后运行 `node scripts/install-desktop.mjs --apply`。脚本备份桌面profile配置，添加本地链接并保留其他插件；已有同名不同安装不会覆盖。自定义DSH目录可通过 `DSH_HOME` 指定。
4. 保存工作并正常重启DSH，在设置打开蓝色小电视“B站浏览”。
5. “高级”选择已有工作区，绑定唯一汇总对话；准备Python依赖、检查环境并扫码登录。升级保留原绑定，不重复创建。
6. 先输入一个有字幕的BV号生成预览。自动浏览、评论发布、私信、自主学习、80/100分互动均由面板开关控制，按需开启。

不要在多个位置同时安装同名插件。采用本地链接安装时，移动或删除源码目录会导致插件无法加载。卸载时先在DSH关闭相关功能，再从桌面profile移除该包的依赖与bundle引用；不要删除整个profile或数据目录。

附带的 `.tgz` 是相同代码的运行包，供兼容的DSH包管理流程使用；它不是已发布到npm的包。源码ZIP包含安装及验证脚本。升级到0.1.0时请准备Python依赖，以使用固定的Brotli1.2.1安全版本；旧解码器会被适配器拒绝。

完整操作：[USER_GUIDE.md](USER_GUIDE.md)。安全边界：[SECURITY.md](SECURITY.md)。更新：[CHANGELOG.md](CHANGELOG.md)。许可与参考：[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

```powershell
node scripts/check.mjs
npm test
python -m pip install -r python/requirements.txt
python -m unittest discover -s tests -p '*_test.py' -v
```

Windows链接和进程回收测试需要可创建链接/查看本进程的普通原生环境；受限沙箱可能返回EPERM。测试使用合成临时目录和模拟SDK，不需要真实B站账号。可选转写测试需要单独安装 `python/requirements-audio.txt`；模型权重单独配置，不随包发布。
